### P2-3 / P2-4 final-review follow-ups

Approved with these minor items open:

- `packages/log`: a log call can throw on an Error whose `message` is not a string or whose getter throws, and on a revoked or trapping Proxy (`scrub.ts` `walkError`, `isPlainObject`). Read those inside `try` and coerce with `String()`.
- `packages/log`: objects and Maps with ~1M entries are fully read before the node budget applies (`readEntries`, `[...map]`). Stop after `MAX_NODES`.
- `packages/log`: prefixed error codes such as `FST_ERR_*` are redacted; accept `^[A-Z]{2,10}_ERR_[A-Z0-9_]+$`.
- `packages/crypto`: key material and plaintext come from Node's shared Buffer pool (`Buffer.concat`, `Buffer.from`). Copy into `Buffer.alloc` (unpooled).
- `packages/crypto`: AAD fields with lone surrogates encode to the same bytes as U+FFFD. Reject `!isWellFormed()` with `invalid_context`.
- Nits: key names `passwordHash`, `pat`, `bearer`; `msgPrefix` not scrubbed; non-object `child()` bindings; `AggregateError.errors` dropped; string plaintext temp buffer in `keyring.encrypt` not zeroed; document that `rewrapDataKeys` skips keys already on the current KEK.

### P2-1 / P2-2 / P2-5 / P2-6 final-review follow-ups

Approved with these minor items open:

- The provisioning check in migration 0001 covers only plpgsql and sql and runs once. Check every trusted language (`pg_language where lanpltrusted`), and repeat the checks on every `migrate()` run or at server start (catches drift, restores, and direct grants to the login role).
- Plain `SET` (e.g. `search_path`, `statement_timeout`) inside `withOrg` persists on the pooled connection for the next tenant. It can't expose data (the app can't create objects), but it can break queries. Run `RESET ALL` before `begin`, or refuse `SET` that isn't `SET LOCAL`.
- Nits: revoke the `lo_*` large-object functions from PUBLIC (global storage outside tenancy); use `search_path = pg_catalog, pg_temp` on the SECURITY DEFINER functions.

### P2-3 dump-test review follow-ups

Approved with these minor items open:

- `findKeyMaterial` (`packages/crypto/src/testing.ts`) has no octal `bytea_output = escape` form for key bytes, so a raw key in a future `bytea` column dumped in escape format would not be found. Current secret columns reject raw bytes.
- `replaceOrgDataKey` checks only the version: require `version === expected` (re-wrap) or `expected + 1` (rotation), and ideally compare the stored wrapped bytes.
- Add a concurrency test for the insert-once and compare-and-swap writes (two `withOrg` in `Promise.all`, exactly one succeeds).
